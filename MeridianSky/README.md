# Meridian Sky
Real-time star view (alt 12–42°, az ±15° of the meridian) for Android 7+.

## Build the APK on GitHub
1. Create a new GitHub repo and push this folder to it.
2. Open the **Actions** tab → **Build APK** (runs on every push, or press *Run workflow*).
3. When it turns green, open the run and download the **MeridianSky-debug-apk** artifact (zip containing `app-debug.apk`).
4. Copy the APK to the phone and install it (allow "Install unknown apps").
